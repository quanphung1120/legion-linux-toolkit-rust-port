## Key decisions recorded (2026-08-03, repo owner)

- GUI framework: **Slint** (over Tauri v2 and cxx-qt) — maintainability first.
- **English only** (drop the 11-language inline dict).
- **Rewrite includes a daemon**: a new Rust `legiond` system service over
  D-Bus (asusctl's asusd model). Note: this is not LLL's C daemon — LLL is
  the (unused) out-of-tree kernel module project; only the name is reused.
- **Primary platform: Ubuntu 26.04 LTS + GNOME Wayland** (owner's system,
  verified: GNOME Shell 50.1, ubuntu-appindicators enabled by default,
  apt cargo 1.93 → MSRV 1.93). .deb via cargo-deb is the first-class
  package; Arch/PKGBUILD secondary.
- Backend: **upstream kernel drivers** (`lenovo-wmi-gamezone`/`-other`,
  `ideapad_laptop`, `charge_types`), not the out-of-tree LLL module — LLL
  doesn't support the owner's 82WM (R9000P ARX8) and doesn't build on
  kernel 7.0; its functionality was mainlined.
- Dropped features: Display page, theme switcher, envycontrol GPU switching,
  ThinkPad/Yoga/multi-brand support, keyboard RGB (hardware is the white-only
  048d:c103 variant), Overclock page (replaced by the three PPT sliders),
  Actions page, L1 AI Engine toggle.

## Findings considered and rejected

- **Keyboard RGB support**: rejected — the 82WM has the white-backlight
  keyboard (USB 048d:c103); no userspace tool supports it and the 4-zone
  protocol doesn't apply. 3-level backlight via `platform::kbd_backlight`
  is in the plan instead.
- **Fan-curve editor**: rejected — no kernel interface exists (upstream has
  at most target-RPM hwmon, absent on this kernel; LLL's curve is broken on
  this model, 0 points).
- **Display Overdrive / G-Sync toggles**: rejected — LLL-only sysfs nodes,
  absent on this machine; no upstream interface today. Revisit if
  lenovo-wmi grows one (feature-detect design will surface it).
- **Porting the LLL DKMS install machinery**: rejected — target the upstream
  ABI instead (kernel ≥ 6.19 recommended, 7.0 verified).
